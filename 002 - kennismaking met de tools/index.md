## Richtlijnen

- 1u40m praktijk
- 10m opkuis
  - groepje per groepje alles inleveren

---

## Opdracht 1

- verdeel in groepen van 2
- headset opstarten (knop links)
- setup op headset
- testen link met PC in Horizon PC app

---

## Opdracht 2

- installeer *Aircar*
  - kan ook in Steam
- ga in een stoel zitten
- start op in link mode
- wen aan de controls
- vlieg rond in de stad
- vlieg even aan hoge snelheid, met bochten
- wissel met je partner

---

## Opdracht 3

- volg de [inleiding tot Godot XR](https://docs.godotengine.org/en/stable/tutorials/xr/setting_up_xr.html) (C♯)
  - *lees ook de uitleg*, stel eventuele vragen
  - Meta Horizon settings vereisten toegang externe app
  - start steeds de game **voor** je headset opzet
- voeg een mesh toe aan elke controller
  - mag een simpele vorm zijn

---

## Opdracht 4

- breid uit tot [A better XR start script](https://docs.godotengine.org/en/stable/tutorials/xr/a_better_xr_start_script.html)
- controleer tussendoor de werking van nieuwe functionaliteit
- maak een Git repository aan waarin je je Godot project bijhoudt
